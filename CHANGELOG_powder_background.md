# Powder background scattering update

- Powder mode now draws a vertical line at each selected background sample peak, using `Q = 2π/d`.
- Line opacity follows the peak intensity, matching the existing single-crystal ring display.
- Hovering a background line shows the sample name, reflection index (when present), Q, and intensity.
- The Instrument setup > Geometry selector is hidden in powder mode and remains available in single-crystal mode.
- Single-crystal behavior and the resolution calculator are otherwise unchanged.
