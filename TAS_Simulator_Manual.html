A browser-based planner for triple-axis spectrometer (TAS) experiments. It shows which (Q, ħω) region your instrument can reach, computes motor angles and the scattering triangle, calculates the resolution ellipsoid, estimates measurement time, and converts scan lists to SPICE macros.

  • Live tool: https://hodaka-kikuchi.github.io/TAS_Simulator/
  • Source: https://github.com/Hodaka-Kikuchi/TAS_Simulator

All screenshots were taken from the running application. The examples use TAX@HFIR (Ef = 14.7 meV) and a bcc iron-like crystal (space group 229, a = 2.866 Å, scattering plane (100)/(010)).

1. Screen layout and workflow

Typical workflow:

  1. Choose the instrument (Section 2).
  2. Describe the sample and orientation (3), optional backgrounds and dark angles (4–5).
  3. Explore reachable space (6) and compute angles (7).
  4. Check resolution (8).
  5. Build the scan list, estimate time (9) and export SPICE (10).

3. Sample

Type. Single crystal uses lattice, scattering plane and orientation. Powder hides those and works with |Q| only (Section 6.3).

Space group. Type a number (1–230) in Space group # or pick from the Space group list. The lattice fields are then constrained by symmetry: for cubic group 229, b and c become read-only and follow a (a tooltip says "b = a by cubic symmetry"), and the angles lock to 90°.

Select CIF / Clear. Loads a CIF; its name appears in the grey box.

Lattice parameters. a, b, c (Å) and α, β, γ (deg).

Scattering plane. Enter U and V (h k l). W is derived automatically ("auto: (0, 0, 1)"). The ↕ button swaps U and V.

Propagation vectors. A first vector k1 (k1_h, k1_k, k1_l) exists by default; + Add propagation vector adds more, Remove deletes one, and the show checkbox toggles the red magnetic-peak markers on the maps.

Sample orientation. Choose how the crystal sits relative to the beam:

  • ki ⟂ U, ki ⟂ V, ki ∥ U, ki ∥ V;
  • Bragg peak position — enter h, k, l and the observed S1 (deg) of that peak. A warning appears if the HKL is outside the U–V plane.

Background scattering. + Add background adds BG1, BG2, … selectors with choices None, Al, Cu, Fe, Ti, W (bundled powder CIFs). Their powder rings appear on the Constant E map and, on the Q vector–E map, where each ring crosses the HKL path. Remove deletes one.

4. Dark angle

Dark angles mark angular regions blocked by sample environments (cryostats, magnets, stoppers).

  • The top show checkbox displays all dark-angle overlays; each dark angle also has its own enable checkbox.
  • Sample environment presets: Standard, MAG-I (vertical magnet), Horizontal Magnet, Pressure Cell, Uniaxial Pressure Cell, Direct beam stopper. Choosing one fills the reference and ranges.
  • Reference: Reference Q (then give h, k, l), Direct beam, or Fixed.
  • Rotation (deg) rotates the environment.
  • Range table (No. / From / To / Offset): + Add range adds a blocked interval, Remove deletes one.
  • + Add dark angle adds another environment; Remove (top right of each) deletes it.

The geometry tools report ki blocked, kf blocked or fixed blocked when a setting falls in a blocked region.

5. Q-E Range overview

The Q-E Range tab computes the accessible region from the S1/S2 limits, energy mode, λ/2 option and dark angles.

6. Q-E Range tab

6.1 Constant E map

  • The title lists instrument, fixed energy, lattice, space group and plane.
  • Yellow area = Accessible Q; black dots = nuclear Bragg peaks (labels can be switched off with Display labels of nuclear Bragg peaks); red dots = magnetic peaks from the propagation vector; coloured circles = background powder rings.
  • Q unit: Å⁻¹ or r.l.u.
  • ħω (meV) slider and box select the energy transfer; S2 (deg) slider and box draw a constant-S2 ring.
  • The white central disc is the region excluded by the minimum S2 / dark angle.

6.2 Q vector–E map

Enter HKL 1 and HKL 2; the plot shows energy against position along that line. Dotted lines mark the end points, every integer-HKL position inside the range is labelled, and the legend matches the Constant E map. Entries are applied shortly after you stop typing (and immediately when you commit the edit). A non-blocking warning appears if the path leaves the U–V plane.

6.3 Powder mode

For powders the map is a function of |Q| and ħω, and the angle tool takes an S2 (deg) input instead of HKL.

7. Angle calculation & TAS geometry

7.1 Single

Enter h, k, l and ħω (meV). The result line shows Ei, Ef, Q and the motor angles M1, M2, S1, S2, A1, A2, and the drawing shows monochromator, sample, analyzer and detector together with ki, kf, Q and the U/V axes.

Helper buttons copy the current point into the sample definition: Set U, Set V, ki ⟂ U, ki ⟂ V. The buttons ki ∥ U, ki ∥ V and Set Bragg peak appear when the matching Orientation reference is selected.

7.2 Scan

Enter H/K/L/ħω initial, H/K/L/ħω final and Points (default 11); values are interpolated linearly. The Table columns are No., H, K, L, ħω, M1, M2, S1, S2, A1, A2, Status (3 decimals). Click a row to highlight it.

Typical Status messages are S2 out of range and No scattering triangle; dark-angle blocks and plane warnings also appear here.

Switch to TAS geometry to step through the scan with the Point slider; the selected row stays synchronised. The Single/Scan and Table/TAS geometry choices are remembered after a reload.

8. Resolution tab

Calculation point options: Approximation (Cooper-Nathans or Popovici), Mode (single or scan), Unit (r.l.u. or Å⁻¹).

  • Single: enter H, K, L, ħω; the result updates automatically after a short pause.
  • Scan: enter initial/final values and Points, then press Calculate. The Prev / Next buttons and the slider only change which calculated point is displayed.

Results:

  • A text summary: calculation point, δQ along each reciprocal axis and δħω (a second value in parentheses is given alongside each), the resolution axes (U, V, W) and the motor angles.
  • Four ellipse plots: δħω vs δQ∥U, δħω vs δQ∥V, the scattering-plane ellipse (U vs V), and δħω vs δQ∥W.
  • A collapsible Resolution Matrix (order Q∥, Q⊥, E, Qout).

A warning is shown if the HKL is not in the scattering plane.

Instrument details

The left column holds the parameters the resolution model uses, loaded from the preset:

  • Focusing conditions — monochromator and analyzer: Horizontal / Vertical, H blades, V blades.
  • Collimator conditions (min) — 1st supermirror and m-value; 1st–4th collimators, H and V.
  • Crystal & Mosaic (min) and Component size (m) — collapsible groups (crystal, d-spacing, mosaics, distances L0–L3, beam, monochromator/analyzer pieces, detector).

9. Time estimate

The Time estimate lives in the second sub-tab of the Q-E Range lower card and is mirrored in the Script tab. Press Info to show or hide the built-in help.

Columns: Index, Command, Target, Details, MCU, Fix.

Commands: drive, driverel, scan, scanrel, scantitle, count, wait, loop (its endloop is created automatically).

Target Offered for
Ei, Ef, E, S1, S2 drive, driverel, scan, scanrel
HKLE drive and scan (not relative commands)
br drive only
QE, th2th scan only
ASET targets (temperature, field, field0 by default) as defined in the ASET list

Details

  • Scans use initial final step; HKLE shows separate H, K, L, E boxes and at least one must be ranged (e.g. 0.5 1 0.05).
  • Numeric boxes accept arithmetic, parentheses, fractions and loop variables, e.g. 4/6+(loop1-1)*1/6 or loop1-1.
  • br takes one HKL field with three space-separated values.
  • scantitle takes free text and loop references (T=loop1 exports as T=%i).
  • count uses MCU; wait is in seconds.
  • th2th is treated as a relative S2 scan starting from the S2 reached by earlier commands.
  • ASET rows such as temperature offer one box per <value> in their template (here vti and sample).

Editing. + Add scan, + Copy scan, Remove. Drag a row's Index to reorder (loop blocks move together); Alt-drag moves just a loop boundary. Rows with a problem turn red and a message explains why (scattering plane, scattering triangle, S1/S2 limits, dark angle).

Timing.

  • 1 MCU = _ s and Movement time (%) set the time per count and the overhead.
  • Set now fills Scan start; Calc finish fills Scan finish and prints, e.g., "Estimated duration: 1 h 13 min 44 s (base … + movement … at 1%) / 43 execution steps in 3 commands".
  • Calc MCU works backwards: it rescales unfixed scans so the schedule fits between start and finish. Ranged-scan MCU values act as relative weights, loops and movement are included, fixed-Details commands use MCU = 0, and results are truncated to whole numbers. Tick Fix to protect a row.

10. Script tab

Three panes work together:

  1. ASET — SPICE templates for non-motor targets. Use <value> for one value and <range> for initial/final/step; repeat placeholders for several boxes; separate commands with commas or line breaks. Defaults: temperature → drive vti <value>, drive sample <value>; field → drive field <value>, drive ramp 1; field0 → drive zero 1. For scan/scanrel lines, preset mcu is added from the row's MCU. + Add ASET adds a template, the × button removes one, Info shows help and ◀ Hide ASET collapses the pane.
  2. Time estimate commands — the same table as in Section 9.
  3. SPICE macro — → SPICE converts commands into macro lines (above: scan h 0.5 1 0.05 k 0 l 0 e 5 preset mcu 60); ← Commands parses a macro back into rows; Copy copies it. Both conversions are one-shot: editing one side never overwrites the other until you press a button. Loop references export as %i, %j, ….

11. Toolbox

Unit conversion

Edit any of wavelength, energy, wavevector k, frequency, temperature, wavenumber, velocity and the others update. The table lists the same quantities for 1/3 λ, 1/2 λ, λ, 2 λ and 3 λ.

S2 conversion

  1. Choose the X-ray source (Cu, Mo, Co, Fe, Cr, Ag Kα1 or Custom; the wavelength stays editable).
  2. Type one or more space-separated observed X-ray S2 values.
  3. Read the neutron wavelength (from the current fixed instrument energy), the neutron S2 and d, all read-only; several results are space-separated. Unreachable angles show a warning.

Neutron attenuation

  1. Select CIF (here Fe.cif).
  2. Enter Energy (meV); wavelength follows.
  3. Set Sample thickness (mm) (box or slider) and, if needed, SE transmission (%) — an extra transmission factor for the sample environment (default 100).
  4. Read Overall transmission (%). You can also type a target overall transmission and the thickness is solved (it cannot exceed the SE transmission).

Output cards: cell volume; absorption, coherent and incoherent cross sections (cm⁻¹); 1/e penetration depths; transmission (Abs, Sample total, Overall); an atom table (atoms per cell, absorption, scattering, ratio); and a transmission-versus-thickness plot with your setting marked.

12. CIF Generator

  1. Space group: type the number or choose from the list (a one-line summary shows crystal system and symmetry-operation count).
  2. Copy current lattice copies the main simulator's lattice; edit a, b, c, α, β, γ (symmetry-locked fields are read-only).
  3. Atomic positions: Atom, x, y, z, Occupancy; + Add atom, + Copy atom, Remove.
  4. Generate builds the CIF; edit File name and Download CIF. Load CIF imports a file; Set CIF sends the CIF to the main simulator.
  5. Energy / Wavelength / Wavevector k set the neutron energy used for the reflection list.

The Reflection table shows Index (h k l), |F|² (barn), Multiplicity, Total |F|², 2θ, Q and d, using nuclear structure factors from bundled neutron-scattering data. Sort by clicking |F|²; filters: along U, along V, within instrument 2θ max and λ/2. Download table exports it.
